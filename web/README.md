# web · Frontend de CitaRENIEC Huánuco (Angular 21)

```bash
npm install
npm start        # http://localhost:4200
npx ng build     # compilación de producción en dist/web
```

La API está simulada en el navegador (`src/app/nucleo/api/base-datos.ts` y `src/app/epicas/*/api/`).
Ver el `README.md` de la raíz para los usuarios de prueba y la estructura de carpetas.
